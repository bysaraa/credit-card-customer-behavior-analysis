# credit-card-customer-behavior-analysis
An interactive Power BI dashboard analyzing credit card customer behavior, spending patterns, credit utilization, payments, and customer insights.

📌 Project Overview

This project analyzes credit card customer behavior using Power BI. The goal is to explore customer spending patterns, credit behavior, payment performance, and customer insights.

🎯 Objectives
- Analyze customer spending behavior
- Compare spending across card types
- Explore the relationship between credit utilization and credit score
- Analyze payment behavior
- Identify customer insights and behavioral patterns
- Build calculated KPIs using DAX

📊 Dashboard Pages

1. Overview

Provides a high-level overview of customer and financial performance.

Key KPIs include:
- Total Customers
- Total Monthly Spending
- Total Outstanding Balance
- Total Reward Points Earned
- Average Annual Income
- Average Credit Score
- Average Payment Ratio

2. Customer Spending Analysis

Analyzes customer spending behavior across different categories.

Includes:
- Average Monthly Spending
- Average Transaction Value
- Average Monthly Transactions
- Spending by Age Group
- Spending by Card Type
- Top Occupations by Spending
- Spending Category Distribution

3. Credit & Payment Analysis

Analyzes customer credit and payment behavior.

Includes:
- Average Credit Limit
- Average Credit Utilization
- Average Outstanding Balance
- Average Payment Amount
- Average Payment Ratio
- Average Credit Score

Key relationships:
- Credit Score vs Credit Utilization
- Payment Ratio vs Credit Score
- Credit Score Distribution
- Credit Utilization by Card Type

4. Customer Insights

Explores customer characteristics and behavior.

Includes:
- Age vs Spending
- Income vs Credit Limit
- Reward Points by Card Type
- App Usage by Age Group
- Customers by Occupation
- Customers by Card Type

🛠️ Tools Used
- Excel
- Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis
